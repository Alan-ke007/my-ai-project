# 我的 AI 全栈学习仓库

> 这是我学习「AI 原生全栈开发」的第一个 Git 仓库，用来记录学习过程、沉淀小 demo，最终成长为一个能展示给面试官看的全栈项目。

## 这个仓库会包含什么
- 学习过程中的小 demo（前端 / 后端 / AI 集成）
- 每个阶段的笔记与架构决策记录
- 最终目标：一个用 AI 协作完成、部署上线的全栈项目

## 本地运行
直接用浏览器打开 `index.html` 即可看到第一个 demo（不需要安装任何东西）。

## 技术栈（逐步补充）
- 前端：待定（计划 React + TypeScript）
- 后端：待定（计划 Node.js）
- AI：LLM API / RAG

## 迭代方式
1. 规划要做什么（写 Issue 或笔记）
2. 开分支 `git checkout -b 功能名`
3. 写代码
4. 提交 `git commit -m "改了啥"`
5. 推送 `git push`
6. 合并到主分支，然后回到第 1 步循环
